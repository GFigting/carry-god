# cg-learn

## Purpose
Capture reusable knowledge from completed work without changing the Task's historical facts.

## Trigger
A Task is done or contains a broadly reusable decision, failure, or technique.

## Inputs
Task summary, decisions, evidence, risks, and review findings.

## Procedure
1. Identify the reusable principle and its context.
2. Remove project-specific secrets and incidental detail.
3. Write a concise Markdown learning artifact.
4. Link it from the Task and record a learning event.

## Outputs
Knowledge note, source Task reference, and follow-up recommendation when needed.

## Evidence
Knowledge artifact path and links to the source decision or verification evidence.

## Failure Handling
Skip capture when no reusable learning exists; never invent lessons from unsupported claims.

## Forbidden Behavior
Do not rewrite history, expose secrets, or treat a learning note as acceptance evidence.
