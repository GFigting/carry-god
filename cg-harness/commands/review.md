# /cg-review

## Purpose

Inspect existing work, verify evidence, summarize decisions, or capture reusable learning.

## Route

1. Establish the review scope and comparison point.
2. Inspect the relevant code, task, plan, and evidence.
3. Separate defects, risks, unanswered questions, and acceptable trade-offs.
4. Run focused verification when the claim requires fresh evidence.
5. Write the result to the task evidence and capture durable learning when useful.

## Preferred Capabilities

- `skills/code-review`
- `gstack/review`
- `gstack/qa` for live UI behavior
- `gstack/cso` for security scope
- `ce-compound` or `gstack/learn` for durable learning

## Output

Findings first, then verification status, remaining risk, and a concise change summary. Review does not authorize unrelated edits.
