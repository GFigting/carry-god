# /cg-refactor

## Purpose

Improve internal structure while preserving agreed external behavior.

## Route

1. State the structural problem and target structure.
2. Map current dependencies, callers, and behavior boundaries.
3. Declare behavior, interfaces, data rules, and operational properties to preserve.
4. Choose a staged migration path.
5. Refactor in small coherent steps.
6. Verify behavior and confirm the target dependency structure.

## Preferred Capabilities

- `skills/improve-codebase-architecture`
- `skills/codebase-design`
- `skills/domain-modeling` for domain boundary changes
- `superpowers:writing-plans`
- `gstack/review` for cross-module refactors

## Output

A refactor plan, target-structure note, changed code, and behavior-preservation evidence. Do not include unrelated bug fixes or new features.
