# /cg-work

## Purpose

Build a new capability or complete ordinary engineering work.

## Route

1. Identify the project, Goal, and desired outcome.
2. Clarify only missing decisions that change scope or acceptance.
3. Use a focused plan when the work crosses files, modules, data, or public interfaces.
4. Implement the smallest complete vertical slice.
5. Verify the changed surface and record evidence.

## Preferred Capabilities

- `superpowers:brainstorming` for unclear requirements
- `superpowers:writing-plans` or `skills/implement` for planned work
- `superpowers:test-driven-development` when behavior can be specified by tests
- `gstack/review` for high-risk or cross-module changes

## Output

Code, tests, task record, and verification evidence. Create a prototype first when visual or interaction decisions are unresolved.
