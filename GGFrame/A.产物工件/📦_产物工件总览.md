# 产物工件总览

## 说明

> ⚠️ **产物工件已迁移至 `A.目标体系/GOAL-XXX/产物/`**。本目录仅保留历史引用，不再作为产物的主要存储位置。

## 按目标浏览

```dataview
TABLE
  file.link as "Goal",
  rows.file.link as "产物文件"
FROM "A.目标体系"
WHERE contains(file.folder, "产物/")
SORT file.folder ASC
GROUP BY file.folder
```

---

## 按任务浏览

```dataview
TABLE
  rows.file.link as "产物文件"
FROM "A.目标体系"
WHERE type = "artifact"
GROUP BY task_id
SORT task_id ASC
```

## 按状态浏览

### 草稿 (draft)
```dataview
TABLE
  file.link as "产物",
  task_id as "任务",
  role as "角色",
  updated as "更新时间"
FROM "A.目标体系"
WHERE type = "artifact" AND status = "draft"
SORT updated DESC
```

### 待审核 (in_review)
```dataview
TABLE
  file.link as "产物",
  task_id as "任务",
  role as "角色",
  updated as "更新时间"
FROM "A.目标体系"
WHERE type = "artifact" AND status = "in_review"
SORT updated DESC
```

### 已批准 (approved)
```dataview
TABLE
  file.link as "产物",
  task_id as "任务",
  project as "项目",
  sync_target as "同步目标"
FROM "A.目标体系"
WHERE type = "artifact" AND status = "approved"
SORT updated DESC
```

### 已同步 (synced)
```dataview
TABLE
  file.link as "产物",
  task_id as "任务",
  project as "项目",
  synced_at as "同步时间"
FROM "A.目标体系"
WHERE type = "artifact" AND status = "synced"
SORT synced_at DESC
```

## 按项目浏览

```dataview
TABLE
  file.link as "产物",
  task_id as "任务",
  role as "角色",
  status as "状态"
FROM "A.目标体系"
WHERE type = "artifact"
SORT project ASC, task_id ASC
GROUP BY project
```

## 待同步清单

```dataview
TABLE
  file.link as "产物",
  sync_target as "目标路径",
  role as "角色"
FROM "A.目标体系"
WHERE type = "artifact" AND status = "approved" AND sync_target != ""
SORT updated ASC
```

## 图例

| 状态 | 含义 |
|------|------|
| `draft` | 草稿，Agent 初始写入 |
| `in_review` | 等待人类审核 |
| `approved` | 审核通过，内容冻结 |
| `synced` | 已同步到项目 docs/ |
