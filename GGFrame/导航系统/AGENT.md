# 导航系统 — Agent 使用指引

## 何时读取本板块

- Agent 首次接触本框架，需要了解整体结构和入口时
- Agent 接到任务但不确定从哪个板块开始查找资源时
- Agent 需要快速定位某个角色、流程、工作类型、工具或知识文档时
- Agent 需要理解各板块之间的关联关系时

## 与其他板块的联动

- **根 CLAUDE.md**：Agent 的总入口，定义导航策略和阅读优先级。导航系统是 CLAUDE.md 中「Agent 决策树」落地的第一站。
- **角色体系**：`📑_角色索引.md` 链接到全部角色定义文件。Agent 确定角色后，跳转到 `角色体系/` 读取角色详情和激活指令。
- **工作体系**：`📑_工作类型索引.md` 链接到全部工作类型定义。Agent 确定工作类型后，跳转到 `2.工作体系/` 读取 context_pack。
- **流程引擎**：`📑_流程索引.md` 链接到全部流程。Agent 确定流程后，跳转到 `4.流程引擎/` 读取编排映射。
- **知识沉淀**：`📑_知识索引.md` 链接到全部知识文档。按领域查找参考材料。
- **通用能力层**：`📑_工具索引.md` 链接到全部工具手册和检查清单。

## Agent 操作清单

1. **首次加载**：读取 `🗺️_知识地图.md` 获取框架全景视图
2. **定位资源**：根据任务需要，使用对应的索引文件快速定位目标文档路径：
   - 需要扮演角色 → `📑_角色索引.md`
   - 需要执行某类工作 → `📑_工作类型索引.md`
   - 需要遵循流程 → `📑_流程索引.md`
   - 需要查知识/工具 → `📑_知识索引.md` / `📑_工具索引.md`
3. **跳转执行**：索引页仅提供路径导航，不包含详细定义。定位到具体文件路径后，转到对应板块读取完整内容。
4. **索引文件轻量原则**：索引页只读链接列表部分即可，跳过 Dataview 查询块（这些是为 Obsidian 人类用户准备的动态查询）。
