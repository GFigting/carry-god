## 所有角色一览

```dataview
TABLE WITHOUT ID
  file.link AS "角色",
  category AS "分类",
  status AS "状态"
FROM "1.角色体系"
WHERE type = "role" AND status != "deprecated"
SORT category ASC, file.name ASC
```
