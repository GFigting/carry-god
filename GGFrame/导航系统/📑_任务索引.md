## 按状态浏览

### 进行中的任务
```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  assignee AS "负责人",
  priority AS "优先级"
FROM "任务系统/进行中"
WHERE type = "task" AND status = "in_progress"
SORT priority ASC
```

### 待审核的任务
```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  assignee AS "提交人",
  reviewer AS "审核人"
FROM "任务系统/进行中"
WHERE type = "task" AND status = "under_review"
SORT updated ASC
```

## 按项目浏览

```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  status AS "状态",
  priority AS "优先级"
FROM "3.任务系统"
WHERE type = "task" AND contains(tags, "project/")
SORT tags ASC, priority ASC
GROUP BY tags
```
