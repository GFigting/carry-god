# 目标体系 — Agent 使用指引

## 核心规则

**目标文件（`目标总览.md`）由人类全权维护。** AI 的交互边界：

| 允许 | 禁止 |
|------|------|
| 读取 `目标总览.md` 理解工作方向 | 创建/修改/删除 `目标总览.md` 中的目标条目 |
| 口头建议某阶段已达成（附证据） | 勾选 checkbox 或修改 `目标总览.md` 任何内容 |
| 在任务文件的 `linked_goals` 中引用目标 | 添加/删除/修改目标条目 |
| 写入 `GOAL-XXX/工作记录.md`（分步执行时自动追加） | — |
| 写入 `GOAL-XXX/历史分点.md`（仅人类指令触发） | — |
| 写入 `GOAL-XXX/关联任务/`（创建任务时） | — |
| 写入 `GOAL-XXX/产物/`（产出非代码产物时） | — |

## 目录结构

```
A.目标体系/
├── 目标总览.md               ← 人类唯一维护文件
├── AGENT.md                  ← 本文件
├── GOAL-NNN-系统-模块/        ← 每个 Goal 一个自包含文件夹
│   ├── 历史分点.md            ← AI：人类指令触发，倒序追加
│   ├── 工作记录.md            ← AI：分步执行日志，倒序追加
│   ├── 关联任务/              ← 任务文件直接放这
│   │   ├── TASK-YYYY-NNN.md
│   │   └── TASK-YYYY-NNN-SUB{N}.md
│   └── 产物/                  ← 按任务分目录
│       └── TASK-YYYY-NNN/
│           └── ART-xxx.md
└── 历史目标/                  ← 已完成/废弃goal，整目录移入
    └── GOAL-XXX/
```

## 使用方式

1. 接到任务时 → 读 `A.目标体系/目标总览.md` 了解当前目标方向
2. 阶段交付时 → 若满足某分点标准，口头建议人类勾选
3. 创建任务时 → 在对应 Goal 的 `关联任务/` 下创建任务文件，填写 `linked_goals: ["GOAL-XXX"]`
4. 分步执行时 → 自动追加到 `GOAL-XXX/工作记录.md`
5. 人类发起「将 GOAL-XXX 的已完成分点迁移到历史分点」→ 执行迁移
