## 脚本编写规范

### 通用要求

| # | 规则 | 说明 |
|---|------|------|
| 1 | 所有脚本必须可独立执行 | 不依赖其他脚本的执行顺序或外部状态 |
| 2 | 入参校验 | 必须参数缺失时打印 `usage` 并返回非零退出码 |
| 3 | 幂等性 | 同一脚本重复执行不产生副作用或重复数据 |
| 4 | 错误处理 | 使用 `set -euo pipefail`（Shell）或等价异常处理（Python） |
| 5 | 日志输出 | 关键步骤打印时间戳日志；失败时输出具体错误信息 |
| 6 | 退出码 | `0` = 成功，非 `0` = 失败（不同错误使用不同码） |

## Shell 脚本模板

```bash
#!/usr/bin/env bash
# ============================================================
# 脚本名称: deploy-app.sh
# 描述:     将指定应用部署到目标环境
# 用法:     ./deploy-app.sh -a <app_name> -e <env> [-v <version>]
# 作者:     zhuangjl
# 日期:     2026-05-24
# ============================================================

set -euo pipefail

# ---- 常量 ----
readonly SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
readonly LOG_FILE="${SCRIPT_DIR}/deploy-app-$(date +%Y%m%d).log"

# ---- 默认值 ----
APP_NAME=""
ENV=""
VERSION="latest"

# ---- 工具函数 ----
log() {
    local level="$1"; shift
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] [${level}] $*" | tee -a "${LOG_FILE}"
}

usage() {
    cat <<EOF
用法: $(basename "$0") -a <app_name> -e <env> [-v <version>]

参数:
  -a    应用名称（必填）
  -e    目标环境: dev | staging | production（必填）
  -v    部署版本，默认 latest

示例:
  $(basename "$0") -a user-service -e staging -v 1.2.0
EOF
    exit 1
}

cleanup() {
    local exit_code=$?
    if [ $exit_code -ne 0 ]; then
        log "ERROR" "部署失败，退出码: ${exit_code}"
    fi
    exit $exit_code
}

# ---- 参数解析 ----
while getopts "a:e:v:h" opt; do
    case "$opt" in
        a) APP_NAME="$OPTARG" ;;
        e) ENV="$OPTARG" ;;
        v) VERSION="$OPTARG" ;;
        h) usage ;;
        *) usage ;;
    esac
done

# ---- 入参校验 ----
if [ -z "$APP_NAME" ] || [ -z "$ENV" ]; then
    log "ERROR" "缺少必填参数: -a 和 -e"
    usage
fi

if [[ ! "$ENV" =~ ^(dev|staging|production)$ ]]; then
    log "ERROR" "无效环境: ${ENV}，可选值: dev | staging | production"
    exit 2
fi

# ---- 主流程 ----
trap cleanup EXIT

log "INFO" "开始部署: app=${APP_NAME}, env=${ENV}, version=${VERSION}"

# TODO: 在此处添加实际的部署逻辑
# 1. 拉取镜像
# 2. 执行健康检查
# 3. 切换流量
# 4. 验证新实例

log "INFO" "部署完成: app=${APP_NAME}, env=${ENV}, version=${VERSION}"
exit 0
```

#!/usr/bin/env python3
# ============================================================
# 脚本名称: health-check.py
# 描述:     对所有注册服务执行健康检查并生成报告
# 用法:     python health-check.py [-c config.yaml] [-t timeout]
# 作者:     zhuangjl
# 日期:     2026-05-24
# ============================================================

import argparse
import json
import logging
import sys
from datetime import datetime, timezone
from typing import List, Optional

# ---- 日志配置 ----
logging.basicConfig(
    level=logging.INFO,
    format='{"timestamp":"%(asctime)s","level":"%(levelname)s","message":"%(message)s"}',
    datefmt='%Y-%m-%dT%H:%M:%S',
    stream=sys.stdout,
)
logger = logging.getLogger(__name__)


class HealthCheckResult:
    """健康检查结果"""
    def __init__(self, service_name: str):
        self.service_name = service_name
        self.status = "unknown"
        self.duration_ms = 0
        self.error: Optional[str] = None

    def to_dict(self) -> dict:
        return {
            "service": self.service_name,
            "status": self.status,
            "duration_ms": self.duration_ms,
            "error": self.error,
        }


def parse_args() -> argparse.Namespace:
    """解析命令行参数"""
    parser = argparse.ArgumentParser(
        description="执行服务健康检查"
    )
    parser.add_argument(
        "-c", "--config",
        default="services.yaml",
        help="服务配置文件路径 (default: services.yaml)",
    )
    parser.add_argument(
        "-t", "--timeout",
        type=int,
        default=5000,
        help="单服务超时毫秒 (default: 5000)",
    )
    parser.add_argument(
        "-o", "--output",
        default="health-check-report.json",
        help="报告输出路径 (default: health-check-report.json)",
    )
    return parser.parse_args()


def check_service(name: str, url: str, timeout: int) -> HealthCheckResult:
    """检查单个服务健康状态"""
    result = HealthCheckResult(name)
    # TODO: 在此处添加实际的 HTTP 健康检查逻辑

    # except Exception as e:
    #     result.status = "unhealthy"
    #     result.error = str(e)
    return result


def generate_report(results: List[HealthCheckResult]) -> dict:
    """生成检查报告"""
    healthy = sum(1 for r in results if r.status == "healthy")

            "total": len(results),
            "healthy": healthy,
            "unhealthy": unhealthy,
        },
        "details": [r.to_dict() for r in results],
    }

    logger.info("健康检查完成: healthy=%d/%d, output=%s",
                report["summary"]["healthy"], report["summary"]["total"], args.output)

    # 有异常服务时返回非零退出码

if __name__ == "__main__":
    sys.exit(main())

## Agent 使用说明

当 Agent 需要编写或修改脚本时：

1. **参考模板**：从上述 Shell / Python 模板开始，保持风格统一。
2. **分类放置**：根据功能将新脚本放入对应分类目录（deploy / data-migration / monitor-check / ops-automation）。
3. **更新索引**：在本文档"目录结构"中新增脚本条目。
4. **复用通用逻辑**：优先使用现有工具函数，不重复造轮子。
5. **测试要求**：脚本完成后在 staging 环境执行一次 dry-run 验证。
