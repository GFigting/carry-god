# 通用能力层

## 概述

通用能力层是框架的**离线 skill 库**，存放跨角色、跨工作类型共用的检查清单、工具手册和脚本库。Agent 不直接暴露全部能力，由 TL 按需取用、派发 subAgent 时挂接具体检查清单，避免选择过载。主要包括：

1. **工具集** — 常用工具的标准化操作手册
2. **脚本库** — 自动化脚本索引与使用说明
3. **检查清单** — 确保关键步骤不被遗漏
4. **模板实例** — 非系统模板的常用文档骨架
5. **skills/** — SQL 生成等跨项目共享的离线 skill 模板

## 如何使用

1. **写代码**：先查 [[通用能力层/检查清单/CHK-代码审查检查清单]] 做自检
2. **要上线**：对照 [[通用能力层/检查清单/CHK-上线前检查清单]] 逐项确认
3. **出故障**：按 [[通用能力层/检查清单/CHK-故障响应检查清单]] 不遗漏关键步骤
4. **提交前**：派发代码质量检查员，用 [[通用能力层/检查清单/CHK-项目代码质量自检]] 逐项核对
5. **忘命令**：翻 [[通用能力层/工具集]] 找对应手册
6. **生成 SQL**：读 [[通用能力层/skills/sql-templates/README]] 找对应模板，遵循 [[通用能力层/工具手册/UTIL-SQL管理规范]]
