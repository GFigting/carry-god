# mgmt 系列 — 管理分析指令

## 系列约定

mgmt 系列指令是**框架数据的管理分析工具**——它们读取框架自身数据（Goal、工作记录、任务文件），执行聚合/格式化/估算，产出管理报告。核心特征：

| 特性 | 约定 |
|------|------|
| **独立触发** | 每个 mgmt 指令是一次性操作，执行完毕后返回当前模式 |
| **双模式通用** | TL 和 Teacher 模式均可用 |
| **只读为主** | 默认只读取框架数据，仅写入输出报告文件 |
| **非互斥** | mgmt 指令之间不互斥，可连续触发不同指令 |
| **不切模式** | 执行 mgmt 指令不改变当前 as 模式 |

## 与开发指令的本质区别

| 维度 | as/fw/with 系列 | mgmt 系列 |
|------|----------------|----------|
| 操作对象 | 项目代码 / 框架结构 | 框架数据（Goal、工作记录、任务） |
| 产出物 | 代码 / 配置 / 框架文档 | 管理报告（工时估算、周期汇报） |
| 触发场景 | 开发工作流 | 管理分析 / 汇报 |
| 副作用 | 修改代码/框架 | 仅写入报告文件 |

## 扩展机制

用户可基于 `MGMT-模板.md` 创建自定义管理指令：
1. 复制 `MGMT-模板.md` → `MGMT-{自定义}.md`
2. 填写：触发词、数据源、聚合逻辑、输出模板
3. 放入 `mgmt系列/` 目录即生效（渐进式加载自动发现）

## 触发规则

1. 用户输入 mgmt 系列触发词或自然语言别名 → 直接响应（无需模式检查）
2. 读取对应 `MGMT-*.md`，按定义流程执行
3. 输出报告写入 `A.目标体系/管理报告/` 目录
4. 执行完毕后 Agent 保持当前模式不变

## 加载协议

Agent 检测到 mgmt 系列触发词时：
1. 立即读取对应 `MGMT-*.md` 文件
2. 按指令文件中的「数据源」清单收集数据
3. 执行聚合/格式化逻辑
4. 将报告写入 `A.目标体系/管理报告/` 目录
5. 向用户汇报关键数据摘要
