# /mgmtReport — 周期性工作报告生成

## 触发

- `/mgmtReport daily`、`生成本日日报`、`今日日报`、`日报`
- `/mgmtReport weekly`、`生成周报`、`本周周报`、`周报`
- `/mgmtReport monthly`、`生成月报`、`本月月报`、`月报`

## 适用范围

**TL 和 Teacher 模式均可用**。

## 目的

读取指定时间范围内的框架数据，生成结构化工作报告。

---

## 数据源

| 数据类型 | 来源路径 | 提取内容 |
|---------|---------|---------|
| 目标进度 | `A.目标体系/目标总览.md` | 当期目标列表、各 Goal 分点完成状态 |
| 工作记录 | `A.目标体系/GOAL-*/工作记录.md` | 每个分步的完成情况、时间戳 |
| 任务状态 | `A.目标体系/GOAL-*/关联任务/` | 关联任务的完成状态 |
| 历史分点 | `A.目标体系/GOAL-*/历史分点.md` | 已完成分点的时间线 |

## 时间范围计算

| 报告类型 | 时间范围 | 示例 |
|---------|---------|------|
| `daily` | 当日 00:00 ~ 现在 | 2026-06-15 |
| `weekly` | 本周一 00:00 ~ 现在 | 2026-06-09 ~ 2026-06-15 |
| `monthly` | 本月 1 日 00:00 ~ 现在 | 2026-06-01 ~ 2026-06-15 |

## GOAL 标题解析规则

报告输出前，从 GOAL 标题解析项目名和模块名：

```
GOAL-NNN: FMS-账单及对账单
           ^^^ ^^^^^^^^^^
          项目  模块
```

- **项目名**：取 `:` 后 `-` 前的部分（如 `FMS`、`lasen`）
- **模块名**：取 `-` 后的部分（如 `账单及对账单`）
- 若 GOAL 标题不包含 `:` 或 `-`，则以完整标题作为项目名，模块名留空

### 项目显示名映射

解析出的项目名（简称）需通过映射表转换为报告中的正式显示名：

| GOAL 项目名（解析来源） | 报告显示名 | 说明 |
|------------------------|-----------|------|
| `FMS` | `FMS` | 已是正式名，无需转换 |
| `lasen` | `中台系统` | 拉森中台系统的报告正式称谓 |

- **映射规则**：优先查表，表中无匹配则保持原样
- **维护**：新增项目或需要调整显示名时，在此表追加条目

## 执行流程

### Phase 1: 收集数据

1. 读取 `A.目标体系/目标总览.md`，列出所有活跃 Goal
2. 对每个活跃 Goal，读取 `工作记录.md`，筛选时间范围内的分步记录
3. 读取 `历史分点.md`，筛选时间范围内的已完成分点
4. 从 GOAL 标题解析出项目名和模块名
5. 将解析出的项目名通过「项目显示名映射」表转换为报告正式显示名

### Phase 2: 分组聚合

按 **项目显示名 → 模块名** 两级分组，同一模块下的条目合并：

- **模块下只有一条** → 紧跟模块名同行列出（`【模块名】内容简述，进度:xx%`）
- **模块下有多条** → 模块名独占一行，每条缩进分行列出
- **本期无活动的 Goal** → 不出现在"已完成"中，仅当有"下周任务"时才出现

进度百分比由 Agent 根据工作记录状态**估算**（100% = 已完成，中间值 = 进行中）。

### Phase 3: 解析下周/明日任务

从 `目标总览.md` 各 Goal 的未完成分点中提取，按同样规则组织。

### Phase 4: 输出报告

写入 `A.目标体系/管理报告/{YYYY-MM-DD}-{类型}报告.md`。

## 行为约束

### 必须做
- 以框架数据为唯一来源，不编造内容
- 报告标注数据来源和时间范围
- 内容精简到功能级效果，一句话描述
- 按项目显示名+模块名两级分组，同模块单条合并不换行
- 进度百分比根据工作记录状态估算（100%=已完成，中间值=进行中）

### 禁止做
- 不修改任何框架数据文件
- 不推断未在框架中记录的工作内容
- 不对完成质量做主观评价
- 不输出统计摘要、风险阻塞等管理元素（保持极简）

### 边界处理

| 场景 | 处理 |
|------|------|
| 时间范围内无任何活动 | 报告"本期无工作记录"，仍输出报告文件 |
| 某个 Goal 目录不存在 | 跳过该 Goal，不出现该 Goal 所属项目/模块 |
| 工作记录.md 为空或不存在 | 跳过该 Goal，不出现在"已完成"中 |
| GOAL 标题无法解析项目/模块 | 以完整标题作为项目名，模块名留空 |
| 管理报告目录不存在 | 先创建 `A.目标体系/管理报告/` 目录 |
