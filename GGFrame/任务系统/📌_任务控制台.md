# 任务控制台

任务状态机见 [[任务系统/任务状态机|任务状态机]]，阻塞任务见 [[任务系统/阻塞任务清单|阻塞任务清单]]。

---

## 我的待办

```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  priority AS "优先级",
  due_date AS "截止日期",
  status AS "状态"
FROM "A.目标体系"
WHERE contains(file.folder, "关联任务") AND type = "task" AND status != "archived" AND status != "done"
SORT priority ASC, due_date ASC
```

---

## 待我审核

```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  assignee AS "提交人",
  date(updated) AS "提交时间"
FROM "A.目标体系"
WHERE contains(file.folder, "关联任务") AND type = "task" AND status = "under_review"
SORT updated ASC
```

---

## 全部活跃任务

```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  assignee AS "负责人",
  status AS "状态",
  priority AS "优先级",
  sprint AS "迭代"
FROM "A.目标体系"
WHERE contains(file.folder, "关联任务") AND type = "task" AND status != "archived"
SORT status ASC, priority ASC
```

---

## 近期完成

```dataview
TABLE WITHOUT ID
  file.link AS "任务",
  assignee AS "负责人",
  date(completed) AS "完成时间"
FROM "A.目标体系"
WHERE type = "task" AND status = "done"
SORT completed DESC
LIMIT 10
```
