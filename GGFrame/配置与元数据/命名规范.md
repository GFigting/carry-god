# 命名规范

## 文件命名

### 角色定义
- **格式**：`ROLE-{中文名称}.md`
- **示例**：`ROLE-后端开发工程师.md`、`ROLE-产品经理.md`
- **目录**：`角色体系/{分类}/`

### 工作类型定义
- **格式**：`WT-{中文名称}.md`
- **示例**：`WT-新功能开发.md`、`WT-故障响应.md`
- **目录**：`2.工作体系/{分类}/`

### 任务文件
- **格式**：`TASK-YYYY-NNN.md`
- **示例**：`TASK-2026-001.md`
- **目录**：`任务系统/进行中/`
- **说明**：NNN 为三位流水号，年度内递增

### 任务标题
- **格式**：`[项目缩写]-[模块名]-[开发描述]`
- **示例**：`FMS-对账结算中心-初版开发`、`LASEN-物料对账-违约款配置化`
- **规则**：
  - 项目缩写取自项目注册表的 key（如 `fms` → `FMS`，`lasen` → `LASEN`）
  - 模块名取自项目注册表中对应项目的 `modules` 或 `business_domains` 字段
  - 开发描述为简洁的动宾短语（如"初版开发""违约款配置化""DDD全框架开发"）
  - 框架元任务（非具体项目任务）可省略项目缩写，直接用主题描述

### 流程定义
- **格式**：`PROC-{中文名称}.md`
- **示例**：`PROC-需求到上线.md`、`PROC-代码审查流程.md`
- **目录**：`4.流程引擎/{分类}/`

### 检查清单
- **格式**：`CHK-{中文名称}.md`
- **示例**：`CHK-上线前检查清单.md`、`CHK-代码审查检查清单.md`
- **目录**：`通用能力层/检查清单/`

### 工具手册
- **格式**：`UTIL-{工具名称}操作手册.md`
- **示例**：`UTIL-Git操作手册.md`
- **目录**：`通用能力层/工具集/`

### 会议纪要
- **格式**：`MTG-YYYY-MM-DD-{主题}.md`
- **示例**：`MTG-2026-05-24-迭代回顾.md`
- **目录**：`7.日志与追踪/会议纪要/`

### 日报
- **格式**：`YYYY-MM-DD.md`
- **示例**：`2026-05-24.md`
- **目录**：`7.日志与追踪/日报/YYYY/`

### 周报
- **格式**：`WK-YYYY-NN.md`
- **示例**：`WK-2026-22.md`
- **目录**：`7.日志与追踪/周报/YYYY/`

### MOC 导航页
- **格式**：`Emoji_中文名.md`（可选 Emoji 前缀方便快速识别）
- **示例**：`🗺️_知识地图.md`、`📑_角色索引.md`

### 产物工件
- **格式**：`[GOAL{NNN}]-[{任务序号}-{子序号}-{产物序号}]-ART-{角色缩写}-{产物中文名}.{扩展名}`
- **示例**：`[GOAL101]-[01-00-01]-ART-TL-技术方案设计.md`、`[GOAL101]-[01-01-01]-ART-CR-计划审核报告.md`
- **目录**：`A.目标体系/GOAL-XXX/产物/{任务序号}/`
- **说明**：
  - 角色缩写见产物工件规范中的映射表（TL/SA/BE/FE/CR/QA/OPS/PM 等）
  - `GOAL{NNN}` 为所属 Goal 编号
  - 任务序号为 Goal 内递增的两位序号，子序号 `00` 表示无子任务
  - 产物序号为同一子任务内递增的两位序号（01-99）
  - 详细规范见 `配置与元数据/产物工件规范.md`

### 系统模板
- **格式**：`tpl-{用途}.md`
- **示例**：`tpl-role.md`、`tpl-task.md`
- **目录**：`.obsidian/templates/`

## ID 命名

不同类型文档使用不同的 ID 前缀：

| 类型 | 前缀 | 格式 | 示例 |
|------|------|------|------|
| 角色 | `ROLE-` | `ROLE-{分类}-{序号}` | `ROLE-DEV-001` |
| 工作类型 | `WT-` | `WT-{分类}-{序号}` | `WT-DEV-001` |
| 任务 | `TASK-` | `TASK-YYYY-NNN` | `TASK-2026-001` |
| 产物 | `ART-` | `ART-{角色缩写}-{YYYY}-{NNN}-{序号}-{中文名}` | `ART-TL-2026-008-01-技术方案设计` |
| 流程 | `PROC-` | `PROC-{分类}-{序号}` | `PROC-DEV-001` |
| 检查清单 | `CHK-` | `CHK-{序号}` | `CHK-001` |
| 工具 | `UTIL-` | `UTIL-{序号}` | `UTIL-001` |

---

## 规则总结

1. **标识符用英文/拼音缩写，文件名主体用中文** — 兼顾可读性和工具兼容性
2. **日期统一用 ISO 8601 格式**：`YYYY-MM-DD`
3. **避免在文件名中使用空格和特殊字符** — 用连字符 `-` 或下划线 `_` 替代
4. **归档文件保持原名** — 通过 `status: archived` 标记，不修改文件名
