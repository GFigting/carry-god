# 推荐插件清单

## 核心插件（★★★ 必须安装）

| 插件 | 用途 | 配置要点 |
|------|------|----------|
| **Dataview** | 动态查询和展示文档元数据，实现任务看板、知识索引等 | 开启 JavaScript 查询和行内查询 |
| **Templater** | 高级模板引擎，支持自动日期、文件创建触发、脚本执行 | 设置模板目录为 `.obsidian/templates`，启用自动触发 |

## 推荐插件（★★☆ 强烈建议）

| 插件 | 用途 | 配置要点 |
|------|------|----------|
| **Calendar** | 可视化日历视图，结合 Daily Notes 插件 | 配置 Weekly Note 格式为 `WK-YYYY-WW` |
| **Kanban** | 将任务列表转为看板视图 | 可对 `📌_任务控制台` 创建看板视图 |
| **Quick Add** | 快速捕获想法、创建任务入口 | 配置 Capture 到 `任务系统/进行中/` |
| **Obsidian Git** | Git 版本控制自动备份 | 设置自动备份间隔（建议 30 分钟） |
| **Excalidraw** | 架构图、流程图、协作图绘制 | 用于创建 `角色协作图.canvas` 的替代方案 |

## 可选插件（★☆☆ 按需安装）

| 插件 | 用途 |
|------|------|
| **Tasks** | 细粒度任务管理（checkbox 级），与 Dataview 互补 |
| **Omnisearch** | 增强全文搜索引擎，支持中文分词 |
| **Tag Wrangler** | 批量重命名和管理标签 |
| **Style Settings** | 自定义主题样式 |
| **Projects** | 项目管理视图，类似 Notion 的表格/看板/日历视图 |
| **DB Folder** | Notion 风格的数据库视图 |
| **Note Refactor** | 将长文档按标题拆分为独立笔记 |

## 核心插件配置（Obsidian 自带）

以下 Obsidian 核心插件建议开启：

- **模板 (Templates)**：模板目录设为 `.obsidian/templates`
- **日记 (Daily Notes)**：日记目录设为 `7.日志与追踪/日报`
- **标签面板 (Tag Pane)**：用于浏览标签层级
- **大纲 (Outline)**：用于快速导航长文档
- **书签 (Bookmarks)**：固定高频访问的 MOC 页面
- **关系图谱 (Graph View)**：可视化文档网络
- **白板 (Canvas)**：创建角色协作图等可视化内容
