# 流程引擎

## 概述

流程引擎以 **LangGraph 风格**定义标准工作流程。每个流程由 **节点 (Nodes)** 和 **边 (Edges)** 组成：

- **Node**：一个角色执行的具体动作，有明确的输入/输出/检查清单/超时
- **Edge**：节点间的流转关系
  - 普通边：固定流向（A → B → C）
  - 条件边：基于结果的分支（通过 → B / 不通过 → A 返工）
- **Subgraph**：可嵌套的子流程
