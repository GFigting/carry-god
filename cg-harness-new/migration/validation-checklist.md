# 整理验证清单

- [ ] 根入口能说明启动顺序和边界。
- [ ] `core/` 与 `workflow/` 对同一行为没有互相矛盾的规则。
- [ ] 任务状态机包含开始、阻塞、审查、返工、完成和取消路径。
- [ ] 需求、设计、实施、审查和收尾均有对应门禁。
- [ ] 每个注册能力的路径都存在。
- [ ] 每个能力都有触发条件、输入、输出和适用边界。
- [ ] Codex 入口不改变宿主无关的核心规则。
- [ ] 新框架不依赖具体项目路径、业务文件或 Obsidian 配置。
- [ ] 没有引用被排除的框架目录或文件。
- [ ] 至少按功能、Bug、调研三种场景走通一次加载路径。
