# 本地化技能

本目录保存经过本地化的第三方技能，用于补充 `capabilities/` 中的框架级门禁。每个技能目录均使用标准 `SKILL.md` frontmatter，包含稳定名称和触发描述。

- `capabilities/` 定义任务状态、项目上下文、人工确认和交付证据。
- 本目录定义可复用的细化执行步骤。
- 项目自身约定和用户明确要求优先；技能不能绕过框架的确认、验证或安全边界。

每个引入技能的来源、许可、上游提交和本地化说明见 `../registry/skill-sources.yaml`。新增或更新技能时，必须保留相应许可声明并重新核对关联 capability 的链接。
