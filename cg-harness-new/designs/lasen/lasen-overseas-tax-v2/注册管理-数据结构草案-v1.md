# 注册管理数据结构草案

本草案对应注册管理原型。注册申请负责通用申请信息和办理过程；VAT、EPR / PPWR、授权代表的专属字段在各自管理页面维护。注册申请完成后，通过资产转换生成对应合规资产。

## 实体关系

```text
注册申请 RegistrationApplication
  ├─ 1:N 申请附件 RegistrationAttachment
  ├─ 1:N 办理记录 RegistrationProcessRecord
  ├─ 1:N 变更记录 RegistrationChangeLog
  └─ 0..1 合规资产 ComplianceAsset
          ├─ 1:N 资产附件 ComplianceAssetAttachment
          ├─ 1:N 关联店铺 ComplianceAssetShop
          └─ 1:N 生命周期记录 ComplianceAssetLifecycle
```

## 注册申请

| 字段                      | 类型            | 说明                                                                        |
| ------------------------- | --------------- | --------------------------------------------------------------------------- |
| id                        | bigint          | 主键                                                                        |
| application_no            | varchar(32)     | 申请编号，唯一                                                              |
| registration_type         | varchar(32)     | VAT、EPR_PPWR_PACKAGING、AUTHORIZED_REPRESENTATIVE                          |
| pay_accounts_id           | bigint          | 申请主体 / 结算主体                                                         |
| pay_accounts_name         | varchar(128)    | 主体快照                                                                    |
| country_id                | bigint          | 国家或地区                                                                  |
| country_name              | varchar(128)    | 国家快照                                                                    |
| service_provider          | varchar(64)     | 服务商字典值                                                                |
| owner_user_id             | bigint          | 负责人                                                                      |
| service_end_date          | date            | 服务截止日期                                                                |
| application_status        | varchar(32)     | DRAFT、MATERIAL_PENDING、PENDING_APPROVAL、PROCESSING、COMPLETED、CANCELLED |
| remark                    | varchar(512)    | 申请备注                                                                    |
| asset_id                  | bigint nullable | 完成后关联的合规资产                                                        |
| create_time / update_time | datetime        | 审计字段                                                                    |

## 申请附件

| 字段              | 类型         | 说明                                  |
| ----------------- | ------------ | ------------------------------------- |
| id                | bigint       | 主键                                  |
| application_id    | bigint       | 注册申请                              |
| material_category | varchar(64)  | 资料类别字典值，不在前端自由输入      |
| file_name         | varchar(255) | 文件名                                |
| file_path         | varchar(512) | 文件地址                              |
| version_no        | int          | 同一申请、同一资料类别的版本号        |
| upload_status     | varchar(32)  | UPLOADING、UPLOADED、ARCHIVED、FAILED |
| remark            | varchar(512) | 附件备注                              |

资料类别由统一字典维护。页面按注册类型读取对应字典项并展示数量；不在新增申请弹窗内选择类别或添加类别。每个字典项对应一个上传入口，上传状态和版本号在页面中可见。

## 办理记录

| 字段           | 类型         | 说明                                               |
| -------------- | ------------ | -------------------------------------------------- |
| id             | bigint       | 主键                                               |
| application_id | bigint       | 注册申请                                           |
| from_status    | varchar(32)  | 原状态                                             |
| to_status      | varchar(32)  | 新状态                                             |
| operation      | varchar(64)  | 提交申请、资料补齐、提交审批、服务商回填、资产建档 |
| operator_id    | bigint       | 操作人                                             |
| operation_time | datetime     | 操作时间                                           |
| remark         | varchar(512) | 处理说明                                           |

## 资产转换约束

- 只有 `application_status = COMPLETED` 时允许生成 `ComplianceAsset`。
- 资产类型固定继承 `registration_type`，不可在转换时修改。
- 申请附件转为资产附件时保留原 `version_no`、资料类别和审计关联。
- 转换成功后写入一条办理记录，状态变更为 `COMPLETED`，同时写入 `asset_id`。
- 资产后续服务截止日期、续费、注销和类型专属字段在对应资产管理页面处理。
