# 原型设计目录

`designs/` 保存设计过程中生成的可运行原型、交互探索和视觉方案，不保存外部需求包的原始原型材料。

```text
designs/
├── README.md
├── {项目标识}/
│   └── {原型名称}/
│       └── ...
└── _unassigned/
    └── {原型名称}/
```

- 项目标识必须使用 `registry/project-context.yaml` 中的项目键；未确认归属时使用 `_unassigned/`，不得猜测。
- 同一原型的 HTML、图片、数据样例和说明文件保留在同一原型目录，不按日期平铺。
- 项目归属确认后，整体迁移目录；不改写原型的历史内容或丢弃附件。
- 外部需求包中携带的原型属于原始需求材料，存放规则见 `requirements-inbox/README.md`。
