# 质量门禁

| 门禁 | 核心问题 | 证据 |
|---|---|---|
| 需求门禁 | 做什么、为什么做、什么不做是否清楚 | 需求摘要、验收标准 |
| 设计门禁 | 边界、接口、数据流和失败模式是否合理 | 设计记录、关键决策 |
| 计划确认门禁 | 需要计划的任务是否已输出最终计划并获得人工确认 | 计划、默认判断、待确认决策、确认记录、复核结论（如适用） |
| 实施门禁 | 代码是否按项目规范完成 | 差异、测试、静态检查 |
| 审查门禁 | 是否满足需求且没有高风险缺陷 | 审查报告、修复记录 |
| 提交门禁 | 提交是否聚焦、可追溯且附有本轮验证信息 | 提交标题、正文、差异和验证记录 |
| 交付门禁 | 结果是否被实际验证 | 命令、输出、人工复查项 |
| 沉淀门禁 | 是否提取了下一次可复用的信息 | 知识记录或明确“不需要” |

完成声明必须基于本轮新产生的验证证据。不能把旧运行结果、主观判断或 Agent 自报结果当作验证。
