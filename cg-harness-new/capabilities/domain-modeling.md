# 领域建模与术语治理

## 做法

1. 从需求、页面、接口、数据表和日志中收集领域名词。
2. 逐个确认名词的业务定义、生命周期、边界和允许状态。
3. 主动寻找同义词、歧义词和前后端命名不一致。
4. 用边界场景检验术语是否能解释真实行为。
5. 将确认结果写入 `registry/domain-glossary.yaml`，并在任务、接口和报告中复用标准术语。

## 交付

术语表、领域对象关系、关键不变量、边界场景和需要记录的架构决策。术语不明确时，不能用技术字段名替代业务定义。
