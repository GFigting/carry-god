# 角色体系

角色描述“负责什么”和“交付什么”，不代替能力模块。一个 Agent 可以在一次任务中承担多个角色，但必须明确当前主责角色。

| 角色 | 主责 |
|---|---|
| Tech Lead | 目标、架构、取舍、集成和最终交付 |
| Architect | 领域边界、接口、数据流和长期结构 |
| Developer | 实现、测试、重构和局部技术决策 |
| Quality | 需求符合性、风险、回归和审查证据 |
| Operations | 发布、观测、回滚和运行风险 |

详细协作规则见 `delegation.md`。
