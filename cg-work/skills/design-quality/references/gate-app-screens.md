# 门禁 B：后台界面

适用于被操作的界面：仪表盘、列表与表格、设置、收件箱、编辑器、审批流、监控面板。

后台界面的判断标准不是"好不好看"，而是**在重复使用中是否省力、是否可信、是否不出错**。因此允许并鼓励页面门禁里禁止的很多东西。

## 继承与豁免

| 门禁 A 条目 | 在 B 中 | 说明 |
|---|---|---|
| A1 标题 ≤2 行 | 继承 | 面板标题同样不得折三行 |
| A4 外边距相等 | 继承 | 主内容区左右对齐；侧栏存在时以内容区为准 |
| A5 无空白带 | 继承 | 后台尤其不能出现半屏空洞 |
| A7 正文可读 | 继承 | 正文 ≥16px；表格与密集列表可 14px，主体墨色 |
| A8 三色制 | 继承 | 强调只给主行动与当前选中项 |
| A9 字体预算 | 继承 | 数字可用等宽（`tabular-nums`），等宽只用于数字列，不算第二家族 |
| A10 无渐变 | 继承 | 含图表填充；图表用纯色与透明度档 |
| A11 无装饰 | 继承 | 允许一级克制阴影用于浮层与下拉，仅此一级 |
| A12 无眉标 | 放宽 | 字段标签、列头、分组标题是功能标签，必须有 |
| A13 无编号 | 放宽 | 步骤、版本号、序号是信息 |
| A14 无细线 | **反向** | 分隔线、表格线、输入框边框是功能边界，应有且要安静 |
| A15 无套路卡片 | 放宽 | 重复面板是正常的；禁止的是"装饰性图标卡" |
| A16 图片 ≥4 | 豁免 | 后台以数据为主；有图时必须是真实数据可视化，不是装饰插画 |
| A17 动效 ≥8 | 豁免 | 动效只用于状态反馈与转场，数量不作要求 |
| A18 文字不遮挡 | 继承 | 抽屉、对话框遮挡内容属交互态，允许 |

## 专属门禁

### B1 密度优先
- 判定：首屏在不滚动的情况下，能完成该页最主要的一到两个动作。
- 边界：纯展示型仪表盘允许一屏 4–8 个核心指标；不得为"呼吸感"把关键数据推到第二屏。
- 反例：一屏只有一个巨大的欢迎语和一个空图表。

### B2 选项收敛
- 判定：同一决策点可见选项 ≤4；超过时分组、折叠或渐进披露。
- 边界：筛选器可多，但默认收起为一行，展开后分组。
- 反例：顶部平铺 11 个同等权重的按钮。

### B3 表格可扫读
- 判定：数字右对齐、单位在列头、行高一致、斑马纹或行分隔二选一；关键列在左侧前三列内。
- 边界：可排序列要有明确指示；行内操作收在行尾或悬停出现，不占宽度。
- 反例：所有列居中、金额不带单位、长文本撑破布局。

### B4 四种状态齐全
- 判定：空、加载、错误、无权限四种状态都有设计；空状态给出下一步动作，不是一句"暂无数据"。
- 边界：只有管理员的页面必须做无权限态；首次使用与搜索无结果要区分。
- 反例：加载中只留一片白。

### B5 危险操作分级
- 判定：破坏性操作（删除、停用、批量）与主行动在视觉与位置上分离；不可逆操作需二次确认并说明后果。
- 边界：可撤销操作用 toast + 撤销，不必弹窗。
- 反例：删除按钮与保存按钮同色同位。

### B6 数据可信
- 判定：每个指标有口径说明（时间范围、单位、是否含税/含回流）；无编造虚数；缺数据显示"—"或"暂无"，不显示 0。
- 边界：演示数据必须标 `示例` 水印或在页头声明。
- 反例：图表里画一条漂亮的虚构增长曲线。

### B7 颜色不承担唯一语义
- 判定：状态除颜色外还有文字或图标；图表系列有直接标注，不只靠图例。
- 边界：同一色系内多系列时，用明度台阶 + 直接标注，不用彩虹色。
- 反例：红/绿两个小圆点表示状态，色盲用户无法区分。

### B8 键盘与焦点
- 判定：所有交互元素可 Tab 到达；焦点环可见且不被 `outline: none` 抹掉；对话框有焦点陷阱与 Esc 关闭。
- 边界：自定义下拉、日期选择器必须支持方向键。
- 反例：全站 `:focus { outline: none }`。

### B9 表单可恢复
- 判定：校验错误就地显示并说明如何修；提交失败不丢输入；长表单分段保存或本地暂存。
- 边界：必填项在提交前标注，不靠星号堆叠。
- 反例：提交后整页刷新，用户重填。

### B10 布局稳定
- 判定：数据长度变化不导致布局跳动；长文本省略并给完整值入口；表格横向滚动时首列固定。
- 边界：加载骨架的尺寸必须与真实内容一致，避免加载完成后跳动。
- 反例：用户名长短不同，行高随之变化。

### B11 权限与范围可见
- 判定：用户能看到自己当前所处的组织/项目/环境；跨范围操作有明确提示。
- 边界：只读角色要有只读标识，而不是把按钮变灰了事。
- 反例：在测试环境误删生产数据的入口长得一样。

### B12 无装饰性视觉噪声
- 判定：无渐变发光、无彩色圆角方块装图标、无彩虹图表、无装饰性空状态插画、无悬浮大数字看板。
- 边界：品牌插画可用于首次使用引导，但不得出现在高频操作页。
- 反例：每个 KPI 配一个渐变色圆角方块图标。
