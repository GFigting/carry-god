# 门禁 A：页面

适用于被读、被滚动的界面：落地页、产品页、作品集、活动页、博客首页。后台界面另见 `gate-app-screens.md`。

判定纪律：**任一条不过即不交付**，不按"整体不错"放过。无法判定时按降级路径（见 `measurement.md`）执行并在报告声明。

## 先写主张，再谈门禁

开工前把页面写成清单，一行一个区块：`区块 → 它主张什么 → 用什么证据支撑`。

- 没有主张的区块直接删除，不靠删样式救。
- 默认套路必须显式通过：首屏标题 + 副文案 + 双按钮、logo 墙、三特性图标卡、证言、定价三栏、页脚 CTA。**默认存在即视为未决定**。
- 区块数量不是目标；证据不足时宁可少一个区块。

### 素材诚实

| 允许编造 | 禁止编造 |
|---|---|
| 菜品名、房型名、活动日期、示例用户名 | 客户、评价、媒体背书、logo、经营数据、奖项 |

占位内容必须在报告列出"上线前必须替换"清单。

## 门禁清单

### A1 标题行数
- 判定：所有 `h1`–`h6`，在 1440/768/390 三档下均 ≤2 行。
- 测量：数截图里的视觉行数，不数源码里的换行。
- 边界：英文全大写小字号、单行超长但自动收缩的标题，允许 2 行；3 行即不过。
- 修法顺序：删字 → 放宽测度（容器宽度）→ 最后才缩字号。
- 反例：靠 `font-size: clamp()` 把标题压到 28px 来凑两行，正文尺度随之失衡。

### A2 首屏有主张标题
- 判定：首屏存在一个明确 `h1`，说清"这是什么"，三种合格句式之一：名称 + 用途；产品 + 价格或用途；活动 + 时间地点。
- 边界：作品集可用"人名 + 职业"；纯视觉页仍需要一个语义化 `h1`。
- 反例：`h1` 是品牌口号，看完仍不知道卖什么。

### A3 每个区块有标题
- 判定：除首屏与页脚外，每个区块的第一层内容是有语义的标题（`h2`/`h3`），不是标签、不是数字。
- 边界：全屏图像区块可用不可见标题（`sr-only`），但必须有。
- 反例：连续三个无标题的图片区块，读者不知道在看什么。

### A4 外边距左右相等
- 判定：各宽度下，内容区左右外边距相等；无区块整体偏向一侧。
- 测量：截图量左右留白；误差 ≤2px 视为相等。
- 边界：非对称构图允许单侧为 0，但另一侧必须由图片、色块或第二栏填满，不能只留空。
- 反例：桌面居中、移动端左贴边。

### A5 空白带与刻意留白
- 判定：全页不存在超过半屏高度的纯空白；刻意的整屏留白每页至多一处，且必须有内容支撑（一句话、一个数字、一张图）。
- 测量：按 390 宽度算，空白高度 > 422px 即为超过半屏。
- 边界：`100vh` 的首屏不算刻意留白；加载占位不算。
- 反例：两个区块之间用 `padding: 20vh` 制造"呼吸感"，实际是没内容。

### A6 区块间距
- 判定：桌面端区块垂直间距 120–240px，且明显大于区块内部的行间距与段落间距。
- 边界：后台界面、长文正文页不适用本条（走 B 或正文默认节奏）；短页面（≤3 区块）允许 96px 下限。
- 反例：区块间距 48px，内部段落 32px，全页糊成一片。

### A7 正文可读
- 判定：正文 ≥16px，使用主墨色；次要说明才允许降一级灰。
- 边界：数据密集表、脚注可 14px，但必须非主阅读内容。
- 反例：全站正文 13px `#888` 在浅灰底上。

### A8 配色三色制
- 判定：一底、一墨、一强调；强调色只出现在主行动与至多一处次级位置。
- 测量：统计页面出现的色值，语义上归为三类的允许，实际色值可因透明度产生多档。
- 边界：图表、状态色（成功/警告/危险）不计入强调，但必须自成体系且不抢主行动。
- 反例：六个不同色的按钮并列，用户不知道主次。

### A9 字体预算
- 判定：≤2 个字体家族（通常 1 个），字号层级 ≤5 级，层级靠比例而非颜色。
- 边界：品牌指定双家族（如衬线标题 + 无衬线正文）时算 2 个，不再加第三个。
- 反例：标题衬线、正文无衬线、标签等宽、数字另一种等宽——四个家族。

### A10 无渐变
- 判定：背景、按钮、文字、遮罩均无 `linear-gradient`/`radial-gradient`/`conic-gradient`。
- 边界：照片上压白色文字允许中性半透明遮罩（单色、无渐变方向）；品牌资产强制要求渐变时走 `instruction-contract.md` 让位。
- 反例：深色页面的"高级感"靠一层紫蓝径向光斑。

### A11 无装饰
- 判定：无毛玻璃（`backdrop-filter`）、无发光（`box-shadow` 带彩色模糊）、无静态阴影（浮层与卡片可有一级）、无 emoji、无渐变光斑、无粒子背景。
- 边界：`prefers-reduced-transparency` 下有纯色兜底时，毛玻璃仍判不过——本框架以纯色为准。
- 反例：每个卡片一层 0 8px 24px 的柔光阴影。

### A12 无小标签与眉标
- 判定：标题上方不存在字号 <正文、全大写或字距放大的眉标；无 pill 徽章、"新 ·"角标、`<sup>` 装饰。
- 边界：表单字段的 label、表格列头属于功能标签，不算。
- 反例：每个区块标题上方一行 `OUR PROCESS`。

### A13 无等宽字与编号装饰
- 判定：除代码块外无等宽字体；无 `01 / 02 / 03`、`(001)`、`Step 2`、`§ 3.1` 这类编号装饰。
- 边界：真实步骤条（有序流程）用 `<ol>` 或真实序号，属于信息，不算装饰。
- 反例：三个特性卡左上角分别写 `01` `02` `03`。

### A14 无细线与描边盒
- 判定：无 1px 全宽分割线、无描边卡片、无背景网格线、无裁切角标。
- 边界：表格的行线、输入框边框属于功能边界，允许。
- 反例：每个区块之间一条 `border-top: 1px solid #e5e5e5`。

### A15 无套路卡片
- 判定：无"图标顶置 + 标题 + 两行说明"的特征卡；无成排同构卡片。
- 同构定义：同尺寸、同内边距、同结构、同视觉重量，仅文案不同。
- 边界：后台界面的重复面板不适用（走 B）；真实商品列表允许重复，但必须有真实图片与价格差异。
- 反例：三个特性区，卡片同构，只是图标从 ⚡ 换成 🔒。

### A16 真实图片
- 判定：页面 ≥4 张真实图片（照片、档案图、地图、版画、真实界面截图），通常 6–12 张；SVG 插画、图标、抽象形状不计入。
- 降级：素材现实为"仅纯图形"时，允许 0 张，但必须在报告声明，并用真实排版与色域承担视觉重量；**不允许用灰色骨架假装截图**。
- 反例：产品页用三个灰色圆角矩形代表界面截图。

### A17 动效层
- 判定：全页真实移动的独立元素 ≥8；只动 `transform`/`opacity`；存在 `prefers-reduced-motion: reduce` 兜底（动效归零或时长趋零）；入场分段错峰 60–90ms，不做整块淡入。
- 测量：加载过程与滚动中各截一帧，数位移或透明度变化的元素。
- 边界：后台界面不要求 8 个（走 B）；无 JS 的静态页允许 0，但报告声明。
- 反例：整页 `opacity: 0 → 1` 一次性淡入，算作一个元素也凑不到八。

### A18 文字不被遮挡
- 判定：任何文字、陈述、数据之上无浮层、无 badge、无"限时"角标、无滚动进度条压字。
- 边界：菜单、对话框、tooltip 覆盖内容属于交互态，允许。
- 反例：首屏标题右上角压一个"全新 2.0"胶囊。

## 判定记录

每条结论写成 `A<n> 通过 / 不过（证据：截图或测量值）`。只写"通过"不写证据的判定无效。
