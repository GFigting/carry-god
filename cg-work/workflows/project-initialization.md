# 项目初始化

在首次接入项目或项目上下文失效时使用。本工作流路由到 `framework:project-initialization`，并遵循 [项目接入规则](../core/project-onboarding.md)。创建 `pending` 初始化任务后，执行技能中的事实探测、上下文和需求箱生成步骤；将初始化报告与待确认项写入项目本地目录。用户确认前不进入其他开发工作流。
