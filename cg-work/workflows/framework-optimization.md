# 框架优化

用于演进 `cg-work` 自身的核心规则、工作流、模板、校验器、目录约定、技能索引或框架自有技能；不用于项目业务代码重构。创建 `pending` 任务记录后，先读取 [框架维护](../core/framework-maintenance.md) 中的演进约束，再加载 `framework:framework-optimization`。

该任务按“证据与范围 → 兼容性和迁移设计 → 计划 → 实施 → 审查与验证 → 用户验收和集成决策”推进。技能正文负责每阶段的操作方法；core 负责版本、数据隔离、唯一来源和弃用约束。
