# 归档存储分离实施计划

## 目标

将已归档任务移动到 `tasks/archive/<task-id>/`，并将仅被归档任务引用的需求包移动到 `requirements-inbox/archive/`，同时保证共享需求包和非归档任务引用不被破坏。

## 范围

### 包含

- 归档脚本支持新归档任务移动、历史归档任务补迁移和需求包安全迁移。
- 归档后的相对引用自动调整；归档内容退出常规检查、队列和元数据迁移。
- 文档、版本和测试同步更新。

### 不包含

- 不删除任务证据、不改变状态、不移动共享需求包。

## 需求与验收

- 需求来源：`../../requirements-inbox/2026-10-07-task-archive-storage.md`
- 验收标准：
  - [x] 新归档任务进入 `tasks/archive/<task-id>/`。
  - [x] 仅被归档任务引用的需求包进入 `requirements-inbox/archive/`。
  - [x] 共享需求包保持原位，引用不失效。
  - [x] 历史 26 个已归档任务完成补迁移。
  - [x] 归档内容不进入常规检查、队列和迁移。

## 计划审核

- 需求覆盖：完整，任务目录、需求箱、引用修正和跳过规则均有验收。
- 风险与回滚：仅执行显式 `--apply`；移动前检查目标冲突，需求包按活动引用计数决定。
- 审核结论：通过。
