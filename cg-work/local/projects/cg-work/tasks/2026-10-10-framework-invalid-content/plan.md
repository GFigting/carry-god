# 实施计划

## 目标

移除四个已废弃模板中会诱导新任务复制的旧骨架，同时保留历史路径的兼容说明。

## 范围

包含四个 `core/` 废弃模板和 `VERSION`。不改变现行核心规则、工作流、校验器或历史任务记录。

## 证据与兼容性

- 问题事实：四个废弃文件仍包含完整章节或 YAML 字段骨架，容易与现行唯一来源并列使用。
- 唯一来源：原型规则以 `core/operating-model.md` 为准；需求拆分格式以 `core/decomposition.template.md` 为准；项目路线图格式以 `core/project-roadmap.template.md` 为准。
- 兼容性：保留原文件路径和短替代说明，不删除历史引用目标；仅减少误用内容，兼容性等级为文档修订。
- 验证范围：全文引用扫描、`npm run check`、`node scripts/check-task.mjs`。

## 实施步骤

1. 将废弃模板改为短重定向说明。
2. 修订补丁版本。
3. 运行框架结构和任务校验。
