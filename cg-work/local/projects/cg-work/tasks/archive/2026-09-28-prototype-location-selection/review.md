# 实现审查

## 结论

实现符合已确认设计：多页面原型可选择业务项目仓库或框架项目目录；单页面和不依赖业务仓库的多页面原型继续使用框架设计目录；业务项目仓库内的原型通过项目上下文登记。

## 审查范围

- 核心规则、上下文加载说明、项目上下文模板和 README 已同步。
- `prototype` 技能要求在创建前询问多页面原型的位置，并禁止静默迁移。
- 项目校验器只校验可选的 `prototypes.paths`，不扫描或移动原型文件。
- 回归测试覆盖有效登记和不存在入口两条路径。

## 兼容性

- `prototypes` 为可选字段，历史项目上下文保持有效。
- 当前关联 `job-hunt` 项目未发现实际 `prototypes/` 目录，因此没有伪造上下文登记。
- 原型任务的 `prototype_reference` 和采纳门禁未改变。

## 自审结论

未发现超出需求的业务代码变更、自动迁移或破坏性路径变更。
