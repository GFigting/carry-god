# 交接记录

## 集成方式

保留本次框架工作流、技能、入口文档和回归测试，等待用户验收后创建本地 Git commit；不推送、不部署。

## 使用入口

后续新开发会话先使用 `framework:project-discovery`。用户确认 `new-project` 摘要后再执行 `framework:project-initialization`；既有项目直接加载并校验项目上下文。

## 遗留项

框架没有独立运行时编排器，实际 Agent 需要遵守技能正文中的一问一答和确认门禁。除此之外无已知遗留问题。

## 用户下一步

用户需要验收入口说明是否符合预期；无需额外环境操作。
