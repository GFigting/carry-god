# 学习记录

## 候选经验

复杂需求的“任务拆分”应分为两个阶段：先用 Wayfinder 解决决策不确定性，再将已确定的范围转为可验收研发任务。若缺少路线图级覆盖与关闭记录，父子任务只能表达执行关系，不能证明原始需求是否完整达成。

## 证据

- 既有 LASEN 父任务与子任务仅有单向父引用，缺少完成度、依赖和关闭汇总。
- 新增回归测试验证路线图关闭门禁、禁止自身依赖和完整引用集。

## 适用范围

适用于跨模块、跨会话或存在多个未决关键决策的需求；单一、可独立验收的任务不应被强制纳入路线图。
