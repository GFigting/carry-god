# 学习记录

## 候选经验

- 观察：将所有缺陷无差别地绑定到完整研发产物，会迫使确定性的一行修复产生无效的文件和脆弱的测试。
  证据：本任务的缺失导入修复需要额外创建计划、审查、验证、学习和交接文件，且 TypeScript ESLint 未能直接捕获运行时未导入符号。
  适用范围：根因明确、只恢复既有行为、没有业务或外部边界影响的缺陷。
  对当前任务的行动：新增受校验的轻量 Bugfix 路由，而不是取消标准缺陷门禁。
