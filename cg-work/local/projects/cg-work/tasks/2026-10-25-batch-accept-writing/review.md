## 发现

1. dev 代码用 `import.meta.env.DEV` 条件渲染后，构建分支恒为 false，但 Rollup 未把字符串与写逻辑完全摇树；静态页 DOM 无控件、无请求，bundle 内仍可检索到开发态文案。已在 README 明确说明，避免把「产物不含」说过头。
2. 「≥7 天建议优先处理」与相邻的停留天数同屏出现（如「27 天」+「≥7 天建议优先处理」），信息略重复；保留阈值是为了让规则自解释。
3. 跨项目重名任务 ID 会被接口拒绝（脚本本身取第一个命中），这是对命令行歧义的收紧，不是行为回归。
4. 增量重建复用启动时的 git 与校验结果，因此 dev 页的提交时间线与校验结果可能滞后；徽标已标注「（启动时）」，README 写明 git 提交与框架文件变化需重启 dev server。
5. 验收成功后的整页刷新会重建快照，选择集按「仍可验收」自动收敛；若同时有任务被他人验收，不会把已变状态的项一起提交。

## 遗留

- 无撤销、无并发锁：验收即写文件，同时验收同一任务时后到请求返回 409，误操作只能人工改回。
- 写接口是本机便利工具，没有账号体系；监听地址固定 `127.0.0.1`，若改成 `--host 0.0.0.0` 会暴露给局域网。
- 配置或框架文件变更后 dev server 仍需重启；本次已重启并切到 `127.0.0.1:5173`。
