# 框架优化流程实施计划

## 验收标准

- `framework:framework-optimization` 可作为独立工作流被加载。
- 工作流明确声明所需的设计、计划、审查与验证技能。
- 同名框架自有技能给出证据、兼容性、迁移、版本和验证门禁。
- 工作流与技能索引可发现，框架版本反映兼容新增。

## 步骤

1. 新增工作流，限定其适用对象是 cg-work 的规则、模板、校验器、目录约定、流程和框架自有技能。
2. 新增简洁的框架自有技能，规定证据驱动、兼容性分级、迁移说明和验证要求。
3. 更新维护规则与索引，升级次版本。
4. 运行单元测试、框架全量校验、技能镜像校验和任务校验；记录审查与验证证据。
