# 提交测试清理门禁

用户要求业务项目提交前删除本次任务相关测试，包括已有相关测试，保留无关历史测试。

## 范围与计划

更新本机提交工具 defaults、实现、测试和 README。项目开关配置在 project-defaults.mjs；不将项目规则写入框架 core。执行者复核已有测试后，显式传入删除清单与 --tests-reviewed；工具自动清理提交选择中的测试，提交前拒绝剩余新增/修改测试。支持已删除路径，删除自动进入暂存范围；不推送、合并或部署。

## 兼容性与迁移

本机 CLI 调用约定变更：启用门禁的项目须增加 --tests-reviewed。其他项目行为不变。工具目录是框架既定忽略的本机副本，不强制纳入版本库，不修改框架公共版本号。

## 验证与审查

17 项提交工具测试通过，包括两个项目缺少复核声明时拒绝、dry-run 不删除、已有相关测试删除、新增选中测试清理及无关测试保留。后续补充业务仓库实际执行和 npm run check 结果。

复验：17/17 测试通过，包含已删除受控路径继续提交；业务清理提交仅包含确认的删除路径。npm run check 已通过，收尾再次运行。全量业务编译和测试未运行，本次未改动业务实现。工具属于忽略的本机副本，保持本机维护约定，框架提交只记录任务证据。
