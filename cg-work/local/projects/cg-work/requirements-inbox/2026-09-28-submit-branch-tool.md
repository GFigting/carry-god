# 需求链接提交分支工具

来源：用户对话（2026-09-28）。

## 原始需求

根据需求链接生成可直接提交的本地需求分支：从最新远端基线创建以需求编号命名的分支，生成规范 commit 标题和仅包含需求链接的 commit body；删除测试类、整理文档必须由参数显式指定。工具不联网校验需求链接，不自动 push、merge、deploy 或创建 PR/MR。

## 验收口径

- 支持需求链接、摘要、基线、仓库、任务号、提交类型、scope 和验证模式参数。
- 分支名等于需求编号；创建前 fetch 指定远端基线。
- commit body 只有需求链接一行。
- `--remove-test`、`--update-doc` 和 `--doc-note` 只处理明确指定的仓库内路径。
- 工具放在 `local/tools/submit-branch/`，支持 dry-run。
