# 原始需求：统一任务 documentation 元数据

## 原始需求

统一任务记录中的文档影响字段：`impact` 保持不变；受影响路径使用 `files`；无需文档变更时使用 `reason`。历史 `targets`、`not_needed_reason` 和可选 `summary` 保持兼容，并提供可预览、可显式执行的迁移工具。

## 范围

- 校验器支持并优先规范字段 `files`、`reason`。
- 历史别名继续可读，不能要求业务项目立即迁移。
- 新增任务元数据迁移脚本，默认 dry-run，`--apply` 才写入。
- 框架受管 `cg-work` 任务记录迁移到规范字段。

## 非目标

- 不改变 `impact` 的取值。
- 不删除历史任务证据或改变任务状态。
- 不强制迁移业务项目本地任务记录。
