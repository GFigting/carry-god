# 文档维护技能接入框架

## 原始需求

优化父目录复制到 `skills/` 的文档维护技能，并将其接入 cg-work 框架，使涉及文档影响的任务能够按条件加载该技能。

## 已确认范围

- 将本地技能从 `doc-keeper` 重命名为 `docs-maintainer`。
- 保留现有 docs 发现、UTF-8、代码与文档同步能力。
- 增加文档类型分类、受影响文档清单、唯一来源、质量门禁和收尾证据要求。
- 在技能索引中登记为框架本地化技能。
- 在功能开发、缺陷修复、重构和审查工作流中加入条件引用，仅在存在文档影响或明确提出文档维护时加载。
- 更新框架版本并执行结构、链接和技能引用校验。

## 非目标

- 不修改上游镜像技能及其校验映射。
- 不把文档技能强制加载到所有任务。
- 不修改项目业务代码、项目上下文或用户已有任务记录。

## 验收标准

1. `skills/docs-maintainer/SKILL.md` 存在，frontmatter 名称、目录名和工作流引用一致。
2. `skills/README.md` 能说明该技能的本地化属性和使用场景。
3. 相关工作流包含唯一的 `framework:docs-maintainer` 条件引用，且框架校验器可以解析。
4. 技能正文包含文档分类、影响清单、Single Source of Truth、质量门禁和收尾输出规则。
5. `VERSION` 按兼容新增能力升级次版本。
6. 完成新鲜校验，并在任务验证记录中如实说明既有校验失败项。
