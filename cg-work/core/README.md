# 核心规则

本目录是框架规则的唯一来源。流程和技能只引用这里的规则，不复制正文。

**生命周期与流程**

- `operating-model.md`：核心对象、状态机、交付路径、证据生命周期的规则正文。
- `continuous-learning.md`：任务学习的记录、证据和提升规则。
- `special-operations.md`：外部与高风险操作的触发和授权边界。

**项目上下文**

- `project-context.md`：项目识别门禁、接入与初始化、上下文字段规范和加载规则。
- `templates/project-context.template.yaml`：唯一的项目上下文模板。

**项目侧标准**

- `documentation-standards.md`：项目文档类别、关联边界和维护规范。
- `project-code-standards.md`：项目未覆盖时的通用代码规范。

**仓库与框架治理**

- `naming-and-submission.md`：命名和 Git 提交边界。
- `framework-maintenance.md`：框架自身维护与演进约束。

**现行模板**（位于 `templates/`）

- `templates/parent-plan.template.md`：大任务主任务计划的需求拆分章节格式。
- `templates/product-roadmap.template.md`：项目路线图格式。
- `templates/plan.template.md`：计划结构；原型章节见 `operating-model.md` 的"原型与任务记录"。

不再保留无消费者的废弃模板文件。
