# 大任务主任务计划模板

主任务（`task.yaml` 声明 `role: parent`）与其他任务一样保存在 `tasks/<task-id>/`，无独立索引目录。本文件是主任务 `plan.md` 需求拆分章节的格式来源；目标、范围、验收与实施步骤仍按 [计划模板](plan.template.md) 编写。已确认决策写入 `task.yaml` 的 `decisions` 字段，不在本文件重复。

## 需求覆盖与拆分

| 需求条目 | 覆盖结果 |
|---|---|
| `<原始需求中的一条可验收条目>` | `<子任务 id>：职责摘要` |
| `<另一条>` | `<已关闭决策名称> / `<明确延期时间或条件>` / `<排除及理由>` |

- 每条可验收需求指定一个结果：子任务、已关闭决策、明确延期或排除；不得用「待处理」作结论。
- 实施中新发现的切片直接挂 `parent_reference` 并在此补行，不新建索引文件。
